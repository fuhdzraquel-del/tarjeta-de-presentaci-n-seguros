# Tarjeta digital — Lic. Raquel Fuentes | Allianz

Sitio estático listo para GitHub Pages.

## Archivos

- `index.html` — estructura y contenido.
- `style.css` — diseño responsive.
- `script.js` — animaciones, catálogo, modales y botones de WhatsApp.
- `assets/favicon.svg` — favicon.

## Publicar en GitHub Pages

1. Crea un repositorio, por ejemplo `tarjeta-raquel-allianz`.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `assets`.
3. En GitHub entra a **Settings → Pages**.
4. Selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
5. Guarda y espera a que GitHub genere la URL.

## Personalización rápida

- Los datos de contacto están en `index.html`.
- Los productos y textos están en `script.js`, dentro de `products`.
- Los colores principales están al inicio de `style.css`:
  - Azul oscuro: `#132033`
  - Dorado: `#CAA34A`
  - Turquesa: `#24B9B4`

## Imágenes de portada

Actualmente la portada usa fondos abstractos hechos con CSS para que el sitio funcione sin depender de imágenes externas. Si quieres fotografías, puedes sustituir las reglas `.slide-1` a `.slide-4` en `style.css` por imágenes propias o de un banco con licencia adecuada.
