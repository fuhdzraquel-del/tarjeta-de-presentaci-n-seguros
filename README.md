## Publicarlo en GitHub Pages

1. En tu repositorio, entra a **Add file → Upload files**.
2. Sube el contenido de esta carpeta: `index.html`, `style.css`, `script.js` y la carpeta `assets`.
3. Haz **Commit changes**.
4. Ve a **Settings → Pages**.
5. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Guarda y espera a que GitHub publique la página.

## Importante sobre el logo

El archivo `assets/allianz-logo.png` es exactamente el archivo que proporcionaste para esta versión. No se redibuja ni se sustituye por un logo inventado.
